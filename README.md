# Yashsaxena Tap

## How do I install these formulae?

`brew install yashsaxena/tap/<formula>`

Or `brew tap yashsaxena/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "yashsaxena/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
